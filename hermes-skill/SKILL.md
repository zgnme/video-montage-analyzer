# Разбор монтажа видеореференса

На сервере установлен `/home/hermes/.local/bin/video-montage`.
Исходники: `/home/hermes/ai-tools/video-montage-analyzer`.
Модель по умолчанию: **DeepSeek V4.1 Flash**, API ID `deepseek-flash`,
endpoint `https://codex.sale/v1`, протокол Responses.
Рассуждения по умолчанию `low`; `--reasoning high` доступен для явного углублённого прогона.

## Маршрут

1. Получи нужный видеофайл на сервер. Для Telegram используй доступный инструмент
   скачивания, для поддерживаемых сайтов — `yt-dlp`. Если файл уже есть, используй его.
   Не скачивай видео на Mac. Уточни источник, только если непонятно, какой ролик имеется в виду.
2. Выбери уникальную рабочую папку под `/home/hermes/downloads/video-montage/`.
   Сначала подготовь кадры без платных вызовов:

   ```bash
   /home/hermes/.local/bin/video-montage prepare /absolute/video.mp4 \
     -o /home/hermes/downloads/video-montage/unique-run
   ```

3. Посмотри число окон/кадров в `manifest.json`. Подготовка сканирует весь ролик,
   находит кандидатов склеек, разбивает длинные планы на окна и сохраняет плотные
   последовательности вокруг границ. Внутри планов по умолчанию 4 кадра/с, до 24 на запрос.
   Это не анализ каждого исходного кадра моделью. Очень короткий эффект внутри плана
   может потребовать повторного анализа с `--fps 12` в НОВОЙ рабочей папке.
4. Запусти анализ через выделенный ключ. Для ролика с речью используй `--transcribe`
   (установленный серверный Whisper, без отправки звука в API) либо передай готовый
   таймкодированный транскрипт через `--transcript /path/transcript.txt`.

   ```bash
   /home/hermes/.local/bin/video-montage analyze /absolute/video.mp4 \
     -o /home/hermes/downloads/video-montage/unique-run --transcribe
   ```

   Для ролика без речи пропусти `--transcribe`. Длинную обработку запускай через
   `terminal(background=true, notify=true)` и дождись реального завершения.
   Мак для модели, Whisper и анализа кадров не нужен.

5. Проверь `result.json`: `status=complete` и `completed_windows=total_windows`.
   При `partial` не называй разбор полным: посмотри `failures` и повтори ту же команду
   с теми же параметрами. Готовые результаты переиспользуются.
   Стандартный предел — 300 попыток API за запуск. При остановке по лимиту можно
   продолжить тем же запуском, сохранив существующую папку. Не запускай бесконечный
   цикл повторов при сетевой/модельной ошибке: после одного повторного сбоя сообщи причину.
6. Прочитай `report.md`, дай пользователю краткую монтажную схему: планы и ритм,
   вставки, переходы, титры, движение и конкретные действия для повторения.
   Сохраняй таймкоды и отличай наблюдения от предположений. При необходимости отдай
   полный `report.md` как `MEDIA:/absolute/path/report.md`. `report.html` — локальный
   просмотрщик с кадрами, ему нужна соседняя папка `frames/`; для передачи упакуй
   HTML и frames вместе. Не отправляй manifest.json с локальными путями без необходимости.

## Смысл результатов и ограничения

- Инструмент отправляет серии JPEG с точными временными метками, а не только текст ASR.
  Один текстовый пересказ не заменяет визуальный разбор.
- API с поддержкой изображений не слышит музыку. Локальный анализ энергии даёт
  предполагаемые звуковые акценты, но не идентифицирует биты, инструменты или SFX.
  Не выдавай их за распознанные звуки. Для их идентификации нужен отдельно выбранный
  аудиомодельный маршрут; он не подключён автоматически.
- Имена эффектов и способы воспроизведения — интерпретация модели, а не извлечение
  оригинального проекта редактора. Точный плагин, объектив или настройки не гарантируются.
- Проверены синтетические склейки, короткие вставки и работа API; превосходство
  над всеми видеомоделями на реальных референсах не установлено.

## Настройки и ключи

`video-montage doctor` показывает только наличие ключа, провайдера, модель и зависимости.
Секреты хранятся в `/home/hermes/.config/video-montage/config.env`, права `0600`.
Не печатай этот файл, не вставляй ключ в команду/логи/отчёт.
Не используй Anthropic, основные ключи Hermes или авторизацию Codex для этого инструмента.
Не переключай провайдера или модель автоматически при ошибке; пользователь выбрал
DeepSeek V4.1 Flash. Если меняешь параметры подготовки, используй новую рабочую папку.
Пользователь запретил тесты через Luna из-за стоимости и через Anthropic. На сервере
разрешена только `deepseek-flash` через `MONTAGE_ALLOWED_MODELS`. Не меняй этот список
и не запускай другие платные модели без нового явного выбора пользователя.
В отчёте указывается фактически использованная модель. Ответ 503 от провайдера
не является успешным анализом ролика.
